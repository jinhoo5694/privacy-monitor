# privacy-monitor - mangom edition

망그러진곰 테마. 모니터 훔쳐보는 동료를 귀엽게 퇴치한다.

`⌃⌥⌘H` 한 번 누르면:
- iTerm2 빼고 모든 앱 창을 숨김
- 두 번째 모니터에 망곰이 이미지들과 메시지 전시

`⌃⌥⌘F` 누르면:
- 전 모니터에 오버레이 (완전 차단)

다시 누르면 원상복구.

## 설치 (macOS)

```sh
curl -fsSL https://raw.githubusercontent.com/jinhoo5694/privacy-monitor/bear/install.sh | bash
```

## 이미지

`~/.hammerspoon/privacy-shield/images/bear/` 에 망그러진곰 이미지/GIF를 넣으세요.
지원: `.png .jpg .jpeg .gif .heic .bmp .webp`

## 제거

```sh
curl -fsSL https://raw.githubusercontent.com/jinhoo5694/privacy-monitor/bear/uninstall.sh | bash
```
